# HL47 — Single DuoCar FAT DEB: native menu + Dock battery/heat + fullscreen bubble

## Accepted product scope (Nguyen, 2026-11-13)
- One **signed rootless DEB**, not split sub-packages. Build through GitHub CI, insist every shipped Mach-O is FAT arm64+arm64e; do not accept a renamed arm64-only file as FAT.
- Native app picker preserves actual image by independently bypassing opaque `pane.picker` face and resize `pane.cover` icon for live native VC only. Original menu, selection, hosted TikTok/YouTube, default Dock, keyboard, Zoom, YTZ/AutoHide remain protected. HL45 diagnostic events and HL46 A/B toggles still present.
- When not fullscreen and a valid free Dock rail exists, show separate readable iPhone 🔋 battery and approximate °C/iOS thermal status, without obscuring original Home/Dock/launcher; feature defaults ON and has an in-app switch. If there is no verified space, deliberately log `[vitals] rail-no-room` and do not overlap unknown icons.
- When fullscreen confirmed and original Dock/chrome hidden, remove Dock HUD and show a separate overlay bubble with **local time, battery, approximate thermal reading**. HL31 pan/edge snap + saved Y and HL33 CarPlay-window pass-through. No idle fade/hide. On restore/close/reconnect restore Dock behavior. Original SCPFullscreenController remains the single fullscreen state owner. Neither Voice nor mic modules are built.
- Sampling uses UIDevice battery and optional read-only IOKit temperature only, with thermal-category fallback. GPU sensor and unit calibration **NOT proven**; do not label reading as GPU exact.
