# Original OmniCar 1.0.3 native chrome 4s idle sync — SOURCE ONLY

Approved 2026-10-20: after 4 seconds idle, hide both the original round divider knob (`SCPCarDividerView.knob`) and each original `pane.handle` three-dot button. Existing ratio popup three choices and separate Zoom already disappear when native `hideRatioMenu` fires. Touch in OmniCar **content/root container** reveals only the triggers and resets the 4 second idle clock; it DOES NOT force ratio menu open. Tapping the original invisible knob still opens ratio menu; divider's pan, swap, pointInside, pane callbacks remain original.

The code NEVER changes original `UIView.hidden`/`UIView.alpha`/`userInteractionEnabled`, frame, constraints, cornerRadius, colors or gestures. It modifies the native handle/knob CALayer `opacity` only, saving/restoring each original value. UIKit hit testing still sees the original UIView. It attaches one *failing, non-cancelling, no-delay* `UIGestureRecognizer` to `SCPCarSplit.container`, **not to Apple's system window/dock or 3rd-party app window**. It observes touches in that native OmniCar container but may not see taps delivered to a separately hosted remote app scene/window; actual end-to-end device QA is required for full-screen tap wake coverage. It explicitly rejects global UIKit hooks.

Synchronize with ORIGINAL menu auto-hide: original `SCPCarSplit.hideRatioMenu` (4s `ratioTimer`) is hooked AFTER `%orig`, then immediately suppresses knobs/handles; new 4-second idle NSTimer covers periods when native ratio menu is CLOSED. Original `barTimer` (4s), ratioTimer (4s), trayTimer (4s) and all action callbacks are unchanged. Native `SCPCarDividerView touchesBegan/Ended/Cancelled` keeps controls awake during drag and restarts the idle delay on release. `rootDidLayout` reapplies visibility after original relayout without extending time.

This module is meant to be integrated into one future **com.anlai.omnicar** rootless package. NO separate install is requested and NO DEB or Sileo publication may be performed without user's new approval. It is not yet compiled in Theos or tested on CarPlay. Existing Zoom and Titanium source are intentionally not changed in this implementation.

This excludes distinct ratioKnob popup view.
